# KANTI — Company Profile

Website company profile untuk **PT Karya Anugerah Tijarah (KANTI)**, perusahaan teknologi yang berfokus pada solusi digital dan inovasi.

Website ini menampilkan profil perusahaan, struktur organisasi, bidang usaha KBLI, layanan, proyek, lokasi, dan informasi kontak.

## Fitur

- Halaman profil perusahaan dengan navigasi ke tiap bagian.
- Menu navigasi responsif untuk layar kecil.
- Informasi layanan e-commerce, AI, IoT, keamanan informasi, dan konsultasi IT.
- Galeri proyek dan peta lokasi.
- Tautan WhatsApp, email, dan Instagram.

## Teknologi

- HTML
- CSS (termasuk layout responsif dan animasi)
- JavaScript untuk menu navigasi seluler
- Google Fonts (Poppins) dan Font Awesome melalui CDN

## Menjalankan secara lokal

Tidak diperlukan instalasi dependensi atau proses build.

1. Clone repositori:

   ```bash
   git clone https://github.com/hdrfhlv/Web_Keren.git
   cd Web_Keren
   ```

2. Buka `index.html` di browser, atau jalankan server lokal seperti **Live Server** dari editor.

Pastikan koneksi internet tersedia agar Google Fonts, ikon Font Awesome, dan peta Google Maps dapat dimuat.
